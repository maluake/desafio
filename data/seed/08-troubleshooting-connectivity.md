# Card machine not connecting to the internet (sem conexão)

Getnet machines connect through Wi-Fi and/or a mobile data chip (3G/4G). Check the icons at the top of the screen to find out whether the problem is the chip signal or the Wi-Fi.

## Step-by-step

1. Restart the machine: hold the power button, turn it off, wait 10 seconds and turn it on again.
2. Check the battery: low battery can disable the modem; charge it for a few minutes.
3. If using Wi-Fi:
   - make sure the router is working (test another device on the same network);
   - move the machine closer to the router; weak networks may appear in the list but fail to connect;
   - re-enter the network password in Settings > Wi-Fi; use 2.4 GHz networks when available;
   - captive-portal networks (that require login in a browser) are not supported.
4. If using the chip (3G/4G):
   - keep only one connection active (turn off Wi-Fi in Settings) so the machine falls back to the chip;
   - with the machine OFF, check that the chip is well seated in its slot;
   - the carrier may have temporary instability in your area; wait a few minutes and try again or go to a place with better signal.
5. Try a test transaction or the "Teste de comunicação" option in the machine menu.
6. If it still does not connect, request maintenance or a replacement through the Getnet app (Getnet Brasil) or the Service Center WhatsApp. Getnet replaces faulty machines under the contract.

## Tip

While the machine is offline you can keep selling with the Payment Link (sent by WhatsApp) or Pix through the Getnet app, so you do not lose sales.
